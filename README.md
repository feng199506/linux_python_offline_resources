# Linux 通用科研 Python 离线资源库（轻量分支）

本分支只包含**文本部分**：说明文档及其离线 HTML 版本、登记表、锁定清单、校验文件和脚本。wheel、deb、运行时、固件和系统镜像都不在本分支，它们在 Release [`lpo-full-20261030`](https://github.com/feng199506/linux_python_offline_resources/releases/tag/lpo-full-20261030) 的 33 个 tar 包中，合计约 36.1 GiB。

- 下载与解压：[download_restore_cn.md](download_restore_cn.md)
- 中文说明：[README_cn.md](README_cn.md)
- 离线首页：下载并解压 tar 包后，用浏览器打开 `index_cn.html`

适用范围：Linux x86-64（glibc，参考 Ubuntu 22.04/24.04）CPU 环境与 ARM 开发板，不能用于 Windows 安装。原库只做了静态检查，没有在目标机上实际安装验证。
