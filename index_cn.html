Linux 通用科研 Python 离线资源库（离线首页）

在浏览器中直接打开本页即可，不需要联网。所有本地链接都指向解压后的同一目录；http(s) 链接是上游来源，需要联网。每个 Markdown 说明都有同名 .html 版本，每个 CSV 都有同名 .html 表格视图（含中文的原始 CSV 已加 BOM，可用 Excel 直接打开）。

这些资源用于 Linux x86-64（glibc，参考 Ubuntu 22.04/24.04）以及 ARM 开发板，不能在 Windows 上安装。在 Windows 上下载、解压，只是为了阅读或转存；之后整个目录拷到 Linux 机器上使用。安装方法见 离线安装与使用。本库只做了静态检查，没有在目标机上实际安装验证。
